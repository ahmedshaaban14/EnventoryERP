# نظام إدارة مخزن قطع الغيار

هذا مشروع WPF مكتمل باستخدام .NET 8 و MVVM و SQLite و Entity Framework Core.

## المتطلبات
- .NET 8 SDK
- Windows (لأن المشروع WPF)

## التشغيل
```bash
dotnet restore
dotnet build
dotnet run --project InventoryERP.App
```

## المميزات
- Clean Architecture
- Dependency Injection
- SQLite محلي
- قاعدة بيانات جاهزة مع بيانات تجريبية
- RTL عربي
- واجهة WPF احترافية
